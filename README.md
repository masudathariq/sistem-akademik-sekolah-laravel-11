# 🎓 Sistem Informasi Akademik Sekolah (Laravel 11)

Aplikasi **Sistem Informasi Akademik (SIAKAD)** berbasis web yang dibangun menggunakan **Laravel 11** untuk membantu pengelolaan administrasi sekolah secara terintegrasi, efisien, dan modern.

---

## 🚀 Fitur Utama

### 👨‍💼 1. Admin

* Manajemen Data User
* Data Guru
* Absensi Guru
* Jadwal Absensi Guru
* Rekap Absensi Guru

---

### 🗂️ 2. Tata Usaha

* Tahun Ajaran
* Rombongan Belajar (Rombel)
* Data Peserta Didik
* Penempatan Kelas
* Kenaikan Kelas
* Data Alumni
* Jadwal Mengajar
* Mata Pelajaran
* Surat Keterangan Pindah
* Surat Keterangan Aktif
* Surat Masuk & Surat Keluar
* Rekap Kehadiran Guru
* Rekap Kehadiran Siswa

---

### 👨‍🏫 3. Guru

* Absensi Guru
* Rekap Absensi Guru
* Absensi Siswa
* Rekap Kehadiran Harian
* Rekap Kehadiran Bulanan
* Jadwal Mengajar
* Wali Kelas
* Raport Tahfidz
* Slip Gaji

---

### 💰 4. Bendahara

* Manajemen Transaksi
* Laporan Absensi Guru
* Sistem Penggajian

---

## 🛠️ Teknologi yang Digunakan

* **Laravel 11**
* **PHP**
* **MySQL**
* **Blade Template**
* **Tailwind CSS**

---

## ⚙️ Instalasi

Ikuti langkah berikut untuk menjalankan project secara lokal:

```bash
git clone https://github.com/masudathariq/sistem-akademik-sekolah-laravel-11.git
cd sistem-akademik-sekolah-laravel-11
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

# Sistem Akademik Sekolah — Laravel 11

## Deskripsi Proyek

Sistem Akademik Sekolah adalah aplikasi web manajemen sekolah berbasis Laravel 11 yang dirancang untuk membantu operasional sekolah secara terintegrasi.

Aplikasi ini mendukung pengelolaan data siswa, rombongan belajar (rombel), absensi, raport, jadwal pelajaran, administrasi keuangan, hingga pengelolaan dokumen sekolah dengan sistem hak akses berdasarkan role pengguna.
